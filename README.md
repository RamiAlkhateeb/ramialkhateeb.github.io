# Rami Alkhateeb Portfolio

Static bilingual personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Update project media

Edit `js/projects.js` to add projects, live `tryUrl` values, and optional source/APK/web URLs. For each standard project, add:

- `assets/projects/<slug>/logo.png`
- `assets/projects/<slug>/1.png`, `2.png`, and `3.png`

For Carousel Engine, add `logo.png` and one wide `wide.png` image instead. Missing files show labeled placeholders. Syria FM uses the `syria-fm` folder and URL slug.

Set the Calendly link in `js/config.js` before publishing.
