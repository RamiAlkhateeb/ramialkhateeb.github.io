# Project media

Use `assets/projects/<project-slug>/logo.png` for the logo shown on the app's card and detail page.

Product screenshots go in the project folder as `1.png`, `2.png`, `3.png`, … — all of them appear as plain screenshots on the product detail page. Cards on `nxt7.html` show only the logo.html?slug=<slug>`).

A demo or teaser video can be added as `<project-slug>_teaser.mp4` (e.g. `carousel-engine/carousel_engine_teaser.mp4`) and set as `video`; it plays on the detail page.
